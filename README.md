# 🍽️ Smart Cafeteria Management System

A console-based Java application developed using **Object-Oriented Programming (OOP)** concepts to manage cafeteria operations. The system provides separate modules for **Admin** and **Customer**, allowing menu management, cart operations, and order processing.

---

## 📌 Features

### 👨‍💼 Admin
- Secure Admin Login
- View Food Menu
- Add New Food Items
- Update Existing Food Items
- Delete Food Items
- View Customer Orders

### 👨‍🎓 Customer
- Secure Customer Login
- View Available Food Menu
- Add Food to Cart
- Remove Food from Cart
- View Shopping Cart
- Place Orders

## ▶️ How to Run

Compile the project:

```bash

```

Run the application:

```bash
java -cp src Main
```

---

## 📖 Project Description

This project demonstrates the implementation of a cafeteria management system using Java. It provides role-based access for administrators and customers. The application follows Object-Oriented Programming principles and uses Java Collections (`ArrayList`) for managing food items, carts, and orders.
